SNAKE CLUB — HOW TO RUN

1. Extract the ZIP file.
2. Open the snake-game folder.
3. Double-click index.html, or open the folder in VS Code and use Live Server.

FILES
- index.html : page structure
- style.css  : layout, colors and responsive design
- script.js  : snake game logic

IMAGE SLOT
In index.html, find the section with class="image-slot".
Replace its inside content with your own image, for example:
<img src="images/my-snake-art.png" alt="Snake game artwork">

If you use an images folder, create it inside this project folder.
Controls: Arrow keys / WASD, Space to pause or resume. On mobile, use the on-screen arrows.
Best score is saved in your browser using localStorage.
