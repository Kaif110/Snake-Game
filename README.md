# 🐍 Snake Game

A classic Snake Game built using **HTML, CSS, and JavaScript**. Control the snake, collect food, grow longer, and try to achieve the highest score without hitting the walls or yourself.

## ✨ Features

- 🐍 Classic snake gameplay
- ⌨️ Keyboard controls
- 🍎 Food collection system
- 🏆 Score tracking
- 💥 Game over detection
- 🔄 Restart functionality
- 📱 Responsive design
- 🎨 Clean and simple user interface

## 🛠️ Technologies Used

- **HTML5** – Game structure
- **CSS3** – Styling and layout
- **JavaScript** – Game logic, movement, collision detection, and score management

## 🎮 How to Play

1. Start the game.
2. Use the arrow keys to control the snake.
3. Collect food to increase your score and grow longer.
4. Avoid hitting the walls or the snake's own body.
5. Try to achieve your highest score!
